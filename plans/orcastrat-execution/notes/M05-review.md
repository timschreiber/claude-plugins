## Blocking

- `plugins/orcastrat/skills/run/SKILL.md:325` — In serial mode, Block with GAP first adds the question to plan.md's Open questions and only then says to **keep the blocked attempt**. That step discards the attempt, which runs `git reset --hard <BASE>` and `git clean -fd` (SKILL.md:48). The reset reverts the uncommitted plan.md edit, and the hold directory keeps only the report and failure log (SKILL.md:47). So the GAP question is lost before the Stop commit, and the Stop report tells the user a question is waiting that plan.md doesn't have. The VACUOUS paragraph at `SKILL.md:327` has the same order: it adds "Verify passed before implementation: …" to Open questions, then keeps the blocked attempt. The fix is to add the Open question after the attempt is kept, as Keep a blocked attempt already does for its `- Blocked:` line. (M05-T10, D85)
